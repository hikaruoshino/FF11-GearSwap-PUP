# 🤖 FFXI-GearSwap-PUP (v2.0 Master Edition)

FF11（ファイナルファンタジーXI）のからくり士（PUP）用 GearSwap スクリプト。  
オートマトンの**挑発（ストロボ）**・**フラッシュバルブ**の正確なリキャスト管理、**事前2〜3秒前着替え**、および**マトンTP 930到達時のWS事前換装**を最優先制御で実現する完全自動着替えエンジンです。

---

## 🌟 主な特徴と機能

1. **アタッチメント＆マニューバ連動の事前換装**
   - ストロボ（火マニューバ）＆ フラッシュバルブ（光マニューバ）のリキャスト2〜3秒前をリアルタイム検知し、自動的に敵対心・魔命中装備（`sets.midcast.Pet['Provoke']` / `['Flashbulb']`）へ先回り着替え。
2. **優先度制御アルゴリズム**
   - 挑発/フラッシュ事前着替え ➔ マトンTP 930到達時のWS事前着替え ➔ 通常装備復帰 の絶対優先順位で誤着替えを完全防止。
3. **引き戻し（Deploy / Retreat）独立タイマー維持**
   - マトンを手元に引き戻した際も、地球時間（`os.time()`）で内部リキャストタイマーを継続カウント。位置調整後もリキャスト表示や事前着替えが狂いません。
4. **マトンAI思考猶予＆10秒安全ガード**
   - リキャスト到達から発動までのマトンAIのタイムラグを考慮し、10秒間の安全ガードタイマーを完備。発動せずに放置された場合も自動で通常装備へ安全復帰します。

---

## 📦 ファイル構成

```text
Windower4/addons/GearSwap/data/ (またはキャラ名フォルダ)
├── PUP.lua           <-- スクリプト本体 (タイマー＆優先度制御ロジック)
└── PUP_gear.lua      <-- 装備セット定義ファイル (ヘヨカ+1、羅王改、ニャメ等)
```

1. [Releases](https://github.com/hikaruoshino/FF11-GearSwap-PUP) からファイルをダウンロードします。
2. `Windower4/addons/GearSwap/data/PUP.lua` および `PUP_gear.lua` として配置します。
3. FF11ゲーム内で `//gs reload` または `//gs load PUP` を実行します。
